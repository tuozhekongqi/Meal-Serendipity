# Dish inspiration assets

These files are project-local dish inspiration assets. They do not depict or represent a merchant, live product, inventory, or orderable listing. External URLs may not replace them in inspiration mode.

这些文件是项目本地的菜品灵感资源；它们不描绘或代表任何商家、实时商品、库存或可下单列表。在灵感模式中，外部 URL 不得替换这些文件。

## Provenance

The twelve source PNGs were created for this project with Codex built-in image generation and visually inspected before packaging. The final prompt family was: original editorial food photography, no merchant, text, people, or branding. The generated originals remain in Codex generated storage and are not copied into or modified by the repository.

Each source was center-fitted without stretching, resized to 1200×900, and encoded as a metadata-free lossy WebP with Pillow 12.3.0. Encoding began at quality 82 and was reduced only where required to stay at or below 180 KiB; no file uses quality below 68.
